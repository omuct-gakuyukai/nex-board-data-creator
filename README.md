# Project Name

大阪公立大学工業高等専門学校の高専祭におけるステージイベント向けに、[Nex-Board](https://github.com/nex-board/nex-board)とステージ照明用の演出資料を作成するアプリケーション

## Features

- SvelteKit
- Svelte 5
- TypeScript
- Vite

---

## Requirements

- Node.js >= 20
- bun

---

## Getting Started

### Install

```bash
bun install
```

### Development

```bash
bun run dev
```

ブラウザで

```
http://localhost:5173
```

を開きます。

---

## Available Scripts

| Command | Description |
|---------|-------------|
| `bun run dev` | 開発サーバー起動 |
| `bun run build` | 本番ビルド |
| `bun run preview` | ビルド結果をローカルで確認 |
| `bun run check` | 型チェック |
| `bun run lint` | Lint |
| `bun run format` | コードフォーマット |
| `bun run test` | テスト |
